## 2. 확정된 사실 — 다시 조사하지 마라

전수조사로 확정된 것들이다. 이 값을 의심하는 작업 지시는 시간 낭비다.

### 원천 적재 시각 (KST · 2026-08-07 · 최근 5주 35개 파티션 전수)

| 원천 | 주기 | 적재 시각 |
|---|---|---|
| `maugrowth_marketing_appsflyer_report` | 매일 | 10:00 (D+1) |
| `molocoAD_daily_metrics` (콘솔) | 매일 | **10:01** (관측 최댓값 10:08) |
| `maugrowth_marketing_ad_report` / `adset_report` | **주** | **월 10:15** (전면 재작성 — 직전 완결 주 행이 이때 처음 생김) |
| `appsflyer.cohort_unified` | 매일 | D+2 |

→ **월 09:30 실행은 구조적으로 불가능하다.** 두 업스트림이 모두 비어 있는 시각이다.

### 몰로코 폴백 구조

대시보드 2075 몰로코 차트에서 `IFNULL(콘솔, AF)`이 걸린 컬럼은 `impressions`·`clicks` **2개뿐**이다. 비용은 `ad_report` 유래라 콘솔이 비어도 멀쩡하다.

→ **행수·비용합 검증으로는 이 장애를 원리적으로 못 잡는다.** 검증 지표는 장애 지점과 **다른 원천**에서 와야 한다(그래서 `_afImp` 교차 잣대를 쓴다).

### NFD 한글

BigQuery `Creative_Title` 한글의 **7.9%**(2,288개 중 181개)가 NFD(분해형)다. Supabase는 NFC라 이름 조인이 **무경고로 0건 매치**가 난다. BigQuery 내부 조인은 양쪽 다 NFD라 정상 작동하므로 **시스템 경계를 넘는 순간에만** 터진다.

→ 소재명으로 조인·대조하는 모든 지점에 NFC 정규화 필수. 단 **구글 ACE 행의 U+200B는 의도된 마커**이니 예외.

## 4. 절대 규칙 (어기면 데이터가 상한다)

1. **진행 중인 주는 기록하지 않는다** — 대상은 항상 직전 완결 주 하나
2. **검증 불일치 시 기록하지 않는다** — P1~P6 중 하나라도 걸리면 그 채널은 보류
3. **재실행은 언제나 안전** — 멱등 체크가 중복을 막는다
4. **성공·실패 무관하게 Slack DM**
5. **`0`은 '없음'이 아니다** — 값을 못 받았으면 키를 아예 넣지 마라
   - 근거: `_v25` 4,846행 중 값 0 = **0건**. 반면 `_m_installs`는 5,898행 중 **347건이 0** → **이 키만 0 허용**
6. **행 삭제 후 재삽입 금지** — 제자리 UPDATE 또는 `신규 || payload` 병합
   - 이유: `_m_resReal`(ffprobe 실측)·`_svc`·`_name`은 소스에서 **재현 불가**. 07-27주 146행 중 59행이 보유
   - 병합 방향: **`a || b`는 b가 이긴다.** 보존은 `신규 || payload`, 교체는 `payload || 신규`
7. **소재명 조인은 반드시 NFC 정규화**

## 7. 자주 헷갈리는 것

**"화면 값이 이상하다"는 신고를 받으면 DB부터 의심하지 마라.** 실제로 두 번 다 DB는 정상이었다.

1. **부팅 캐시** — 접속 시 `cr_status` 시그니처로 캐시 재사용을 판단한다. 시그니처에 `dataver`가 들어가 있어 payload 내부 수정도 잡히지만, 의심되면 화면 아래 `☁️` 저장소 줄을 눌러 강제 재로드한다.
2. **배포 지연** — GitHub Pages 배포는 push 후 1~2분 걸린다. `curl -s <사이트> | grep <새 코드 조각>`으로 확인 가능.

**점수(score)는 화면에서 쓰지 않는다.** 계산은 살아 있고(추정 실적·분석 탭이 쓴다) 표시만 껐다. `hidden` 속성과 이른 `return`으로만 껐으니 되살릴 땐 한 줄씩 지우면 된다.

**주차별 실적은 '확신할 때만' 표기한다.** 전 소재에 붙이면 정확도가 71~74%로 떨어져 일부러 3분의 2를 비운다. 자세한 근거와 재보정 절차는 `docs/ARCHITECTURE.md` §9.
