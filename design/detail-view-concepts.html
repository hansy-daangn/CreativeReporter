상세보기 시안 v2 — C 골격 확정, 레일 3변주

좌측 미디어 스테이지 + 우측 데이터 레일(C 골격)은 고정하고, 레일의 골격 자체를 세 방향으로 다르게 설계했습니다. 매체 세그먼트(구글 AEO · 구글 ACE · 몰로코)를 눌러 같은 규칙의 렌더링을 확인하세요. 수치는 검증용 예시 데이터입니다.

✓ 1영상 소재는 영상 시청 유지를 수명 곡선 바로 아래에 — 좌측 스테이지가 미디어·수명·시청을 한 열로 담습니다.
✓ 2추이 탭 삭제 — 모든 지표 행 옆 회색 스파크라인이 대체. 평시엔 회색으로 물러나 있고 행에 마우스를 올릴 때만 잉크색으로 선명해집니다.
✓ 3상세보기의 메타 칩(매체·포맷·해상도·그룹) 전부 삭제 — 해상도·시간·상태는 미디어 아래 한 줄, 그룹명은 비교 행 라벨로 흡수.
✓ 4세그먼트·소제목(<지표>·<비교>) 삭제 — 지표 아래 구분선 하나를 두고 비교(비교군·타매체)가 이어집니다. 남긴 캡션은 코호트 기준 주차·표본뿐(정보라서).

C1

원장 레일

한 열로 정독 — 성과→실증→구분선→비교가 하나의 세로 흐름

레일 전체가 단일 원장입니다. 성과와 실증이 같은 행 문법으로 이어지고, 등급 칩을 유지해 훑을 때 좋고 나쁨이 칩 색으로도 잡힙니다. 위에서 아래로 한 번 읽으면 끝나는, 세 안 중 가장 종이 리포트에 가까운 구조.

상세보기 · 표의 행을 펼친 상태
▾ 표 행 (소재 목록의 현재 행 — 클릭으로 여닫음)
적대자 채점10점 만점 · 피드백 반영 후 재채점
가독성9행 문법 하나, 정렬선 네 줄(라벨·값·스파크·상위%)이 원장 전체를 관통.
공간 활용8한 열이라 세로로 가장 길다. 대신 스테이지의 남는 세로를 수명·시청 곡선이 채워 좌우 높이가 맞는다.
계층·위계9이름·점수 → 진단 → 원장 → 비교의 단선 위계. 등급 칩이 행 사이 강약을 만든다.
미니멀리즘9탭 0 · 소제목 0 · 칩은 등급만. 구분선 단 하나.
직관·간결9"어디를 눌러야 하지?"가 없는 구조 — 전부 한 화면에 이미 있다.
톤앤매너10기존 등급 칩·타이포 스케일 그대로.
라운드에서 잘려나간 것
  • 성과/실증 사이 마이크로 캡션 — 라벨이 자기설명적이라 캡션 없이 여백+헤어라인으로 충분하다고 판정. 코호트 기준 정보는 ⓘ로.
  • 비교 행의 스파크 빈 칸 — 다섯 열을 억지로 채우지 않고 값이 두 열을 쓰게 해 왼쪽 정렬선만 유지.
C2

이열 레일

성과 | 실증 나란히 — 등급 칩까지 걷어낸 최소 잉크, 한 화면 스캔

레일을 성과(매체 리포트)와 실증(유저 단위)의 두 열로 나란히 세웁니다. 등급 칩도 제거하고 값의 색과 상위%만 남긴 최소 잉크 버전 — 스크롤 없이 첫 화면에서 모든 지표와 비교가 끝납니다. 세로가 짧고 가로를 쓰는, 스캔에 최적화된 구조.

▾ 표 행 (소재 목록의 현재 행 — 클릭으로 여닫음)
적대자 채점10점 만점 · 피드백 반영 후 재채점
가독성9열 하나가 좁아 시선 이동이 짧다. 칩이 없어도 값 색+상위%로 판단이 선다.
공간 활용10세 안 중 상세 높이 최소 — 목록으로 돌아가는 스크롤 비용이 가장 적다.
계층·위계8좌=매체가 말하는 성과, 우=유저가 증명한 실증 — 열 자체가 의미를 갖는다. 다만 히어로급 강조점은 없다.
미니멀리즘10칩 0 · 탭 0 · 소제목 0. 잉크가 가장 적은 안.
직관·간결9비교도 같은 2열로 이어져 문법 전환이 없다.
톤앤매너10색·타이포·간격 전부 기존 토큰.
라운드에서 잘려나간 것
  • 등급 칩 — 값 색이 이미 등급을 말한다. 색약 대비는 상위% 텍스트가 담당(색만으로 전달 금지 원칙 유지).
  • 두 열 위 큰 제목 — 열 첫머리의 한 줄짜리 옅은 캡션(성과·실증 기준)으로 축소. 이것마저 없애면 "왼쪽/오른쪽이 뭐가 다르지"가 생겨 남김.
C3

판정 레일

점수·진단·대표지표 3슬롯이 히어로 — 스파크라인이 KPI 안으로

A안의 '판정 우선' DNA를 C 골격에 이식한 안. 점수(34px)·진단·대표지표 3슬롯이 레일 상단을 지배하고, KPI 슬롯 안에 스파크라인이 내장돼 "지금 좋은가 + 좋아지는 중인가"가 첫 시선에서 끝납니다. 나머지 지표는 촘촘한 2열 미니 원장으로 물러납니다.

▾ 표 행 (소재 목록의 현재 행 — 클릭으로 여닫음)
적대자 채점10점 만점 · 피드백 반영 후 재채점
가독성9첫 시선은 판정, 둘째 시선은 KPI 추이, 셋째가 세부 — 읽는 순서가 강제된다.
공간 활용9미니 2열이 세부 지표를 압축해 히어로에 쓴 공간을 회수.
계층·위계1034px 점수 → 23px KPI → 11.5px 세부의 3단 크기 위계가 정보 중요도와 일치. 세 안 중 위계가 가장 또렷.
미니멀리즘8히어로가 쓰는 잉크만큼 C2보다 무겁다 — 의도된 트레이드오프.
직관·간결10"밀까 말까"에 3초 안에 답한다. KPI 스파크가 방향까지 같이 답한다.
톤앤매너934px는 기존 스케일(23px) 위의 예외 1개 — 화면에 하나꼴 히어로 원칙 안에서 허용.
라운드에서 잘려나간 것
  • KPI 슬롯의 중앙값 서브라인 — 스파크가 들어오면서 한 슬롯에 정보 4개는 과밀. 중앙값은 ⓘ 툴팁으로.
  • 진단 문장 강조 배경띠 — 점수가 이미 히어로인데 배경띠까지 있으면 강조가 둘. 민글로 회귀.
